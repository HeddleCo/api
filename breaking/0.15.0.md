# 0.15.0 retired RPC removal

This coordinated pre-1.0 cut removes five RPCs whose Weft handlers have
already been retired:

- `IdentityService/MintBiscuit`
- `IdentityService/RecordSubscription`
- `RegistryService/CreateNamespace`
- `RegistryService/CreateRepository`
- `RegistryService/GetCurrentUserNamespace`

Their six unshared request/response messages are removed with them. Shared
response messages remain unchanged. No field or enum number is renumbered or
reused.

The same batch additively introduces discussion severity on
`OpenDiscussionRequest`, the `OPEN_DISCUSSION` unmet-requirement kind,
installation-scoped GitHub repository listing, and on-demand GitHub App setup
challenge minting.
