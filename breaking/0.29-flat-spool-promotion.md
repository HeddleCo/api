# 0.29: flat spool namespace and promotion (weft#2107 phase 1)

This is an intentional pre-1.0 breaking override. No namespace-prefix migration
or compatibility route is provided. The implementation is foundation-level until
the coordinated server and Postgres acceptance gate land.

- `NamespaceKind` retains its type name but only `SPOOL = 4` is concrete.
  Removed values 1–3 and their names are reserved, never reused.
- `HostedSpool.kind` and `SpoolSummary.kind` contain `spool`; `is_repo` remains
  independent. Canonical full paths start with `spool/`.
- `CreateSpool.parent_path = ""` means the caller's personal root. Bare writes
  are personal-relative. Bare reads prefer the caller's first child segment,
  then the same segment at the shared root.
- New unary `RegistryService/PromoteSpool(PromoteSpoolRequest)` returns
  `PromoteSpoolResponse`. Request tags: `full_path = 1`,
  `client_operation_id = 2`; response: `HostedSpool spool = 1`.
  The generated route is `MethodRoute::RegistryServicePromoteSpool`.
  It is a durable write, requires request PoP and operation-id deduplication,
  requires effective Owner authority, and hides resource existence.
- Promotion retains the resource UUID, owner genesis, is_repo, descendants and
  direct grants. The account must be claimed/verified and the current slug free
  and unreserved at the shared root. Old-parent inheritance ends at promotion.

Release order: publish `heddle-api` 0.29.0 (Rust and TypeScript); update Heddle to
exact API pin `=0.29.0` and publish breaking `heddle-wire` 0.22.0 with its consumer
updates; replace Weft's development path patches with published API `=0.29.0`
and wire `=0.22.0` pins, regenerate its lockfile, verify, then land Weft.
The development manifests retain the current package versions to support local
patching before the coordinated release; the publisher must make these version
bumps before publishing.

Phase 2 consumes the new route/request/response, `NamespaceKind::Spool`, the
literal `spool` kind, independent `is_repo`, and canonical flat paths. CLI verbs
and tapestry UI are outside phase 1.
