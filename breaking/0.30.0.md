# 0.30.0 additive surface — root-attested ephemeral descriptor trust

This release is **purely additive**: a new Rust module with no protobuf, RPC,
or generated TypeScript change. No message is removed, renamed, or renumbered,
and no advertised maturity is withdrawn. `buf breaking --against
'.git#ref=origin/main'` reports nothing — this document is a release record,
not a break report.

## Two-layer descriptor trust contract (api#226)

weft#1835 (producer) and heddle#1566 (consumer) each implemented the
leaderless-iroh "root-attested ephemeral descriptor" wire contract and
diverged. This crate now owns the contract once:

- `heddle_api::descriptor_trust` — `EndpointDescriptorSetDocument`,
  `AttestedEndpointDescriptorEntry`, `ephemeral_attestation_bytes`,
  `verify_ephemeral_attestation`, `trusted_live_entries`.
- Address model is a two-layer chain: the deployment-descriptor **root** signs
  an attestation binding the ephemeral key; the **ephemeral** key signs its own
  `SignedEndpointDescriptor`. Consumers verify both layers and bind
  `descriptor.endpoint_id` to the attested public key.
- Published conformance vector (`descriptor_trust::conformance`) is the
  cross-repo pin for weft (phase 1) and heddle (phase 2).

No TypeScript code change is required; the crate and npm package versions
still move together.
