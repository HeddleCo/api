# alpha.22 contract batch: explicit settings patches and fixed read budgets

Owner-approved on 2026-10-03, tracked by
[api#323](https://github.com/HeddleCo/api/issues/323) and
[api#309](https://github.com/HeddleCo/api/issues/309).
This revises semantics in place, with no complete-record compatibility mode.
The package version is unchanged; this note describes the planned alpha.22 batch.

ReviseSpool.settings is now a field-mask patch. Omitted/empty settings_mask
leaves all settings unchanged; only selected top-level fields are applied.
A selected absent message explicitly clears it. Scalars can explicitly reset
to false/empty/UNSPECIFIED. Clearing requires permission to read and clear the
current stored value. Replacing either filtered reference requires the same
current-value permission, independently of new-target validation; bind both
to expected_version with live authorization at commit. This covers both caller-filtered references,
default_thread and default_review_policy, and all other settings fields. Existing
clients must supply the mask; an overview is never a complete replacement.
See docs/alpha-v2/observation-additions.md for the field audit and design rationale.

ReadBudget above advertised maximums now MUST clamp rather than reject.
Every endpoint must advertise at least 1024 items, 524288 frame bytes and
4194304 snapshot bytes. Transient capacity below min(resolved request, floor)
fails retryably with UNAVAILABLE. Effective budget echoes are mandatory for
observation opens (including resume), finite reads, and transfer/replication
ready frames. Finite stream echoes precede domain events. Structural shape
failures are INVALID_ARGUMENT before matching; larger matching collections
return PARTIAL and continuation. Indivisible ListPaths and code-navigation
results now have explicit admission bounds and per-method minimum budgets,
validated before matching. Older incompatible sources/indexes are unavailable,
not paged forever or truncated. LATEST ObserveRuns uses its existing stream
cursor to finish the fixed initial remainder in bounded UPSERT batches before
following newer positions; it does not accept page tokens or choose a new latest N.
Clients must handle the new initial echo event;
the signed request body and request-proof canonical bytes are unchanged.
See docs/alpha-v2/streams.md for the rules and shared generated budget type.

ThreadOverview.integrated_at is the landing execution time on every overview,
including list rows, paired with integrated_revision. It is unset before landing
and independent of later metadata updated_at changes.

`buf breaking --against '.git#tag=v0.31.0-alpha.20'` exits 0 with no output.
The protobuf changes are additive; Buf cannot detect these intentional semantic
revisions. Producers and consumers must adopt the revised contract together.

The API-only conformance harnesses retain heddle 0.28.7 / API alpha.19, the newest
compatible published pair checked on crates.io on 2026-10-03. The newer standalone
API alpha.20 is not the API pinned by the published 0.28.7 crate set. No weft or
heddle checkout builds, publication, or deployment are part of this change.
