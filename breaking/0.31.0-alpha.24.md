# 0.31.0-alpha.24 — HYBRID renewal discovery and submission

Closes #329 (G1/D1 and G2/D2). Revise the v1 contract in place; there is no
back-compat path or v2 encoding. All seven API version files move together.
The native harness stays on published native 0.28.7 / API alpha.19; those
published verifier crates still require that API pair.

- Add authenticated destination-writer `IntegrationService.GetImportJobState`.
  It returns the existing CAS state and bounded retained accepted authority
  proof in one snapshot, including an explicit empty manifest before publication.
  It recovers lost responses/clients without changing exact Prepare semantics.
- Require read -> remaining-scope computation/review -> exact Prepare -> equal
  snapshot -> sign. A publication/renewal race requires a fresh read and Prepare.
  Activation retains predecessor, epoch and manifest CAS and live authority gates.
- Define the existing Renew proof carrier precisely: exact accepted history,
  retained original genesis parents, exact snapshot references, new permission
  and current owner evidence. The candidate exists only in top-level `renewal`.
  Append accepted history after activation. Freeze complete request bytes for
  idempotent replay; request PoP remains outside that frozen body.
- Add Rust/TS read, race, request composition, separate historical/current owner
  submission verification and raw-byte replay helpers. Zero-publication recovery
  requires no invented admissions. Public export completeness stays unchanged.

Signed HYBRID layouts and domains are unchanged. The new RPC/messages are wire
additions; the clarified mandatory submission profile is a semantic contract
change. Original-scope permissions cannot be substituted for remaining-scope
parents; stable lineage cancellation IDs, fresh nonces, active-delegation Cancel,
time-free predecessor recovery, first-operation lineage and skew-tolerant
preflight retain alpha.23 behavior.

`buf breaking --against 'https://github.com/HeddleCo/api.git#tag=v0.31.0-alpha.23'`
exits **0 with no output**. Buf detects wire compatibility, not these newly
specified semantic requirements.

The shared generator freezes four actual Renew request bodies (partial,
zero-publication, rotated owner, rotated owner plus zero-publication), state
read requests/responses and discriminating rejection/control pairs. Tests load
those bytes in Rust and TS. Byte-limit probes expand the shared vector's declared
`envelope_bytes` length locally to avoid storing multi-MiB rejected octets.
