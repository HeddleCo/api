# 0.31.0-alpha.25 — HYBRID import sources

Closes #331. Revise v1 in place, with no compatibility path or `public_git` alias.
The seven API version files move together. Harnesses remain on the newest
published compatible native 0.28.7 / API alpha.19 pair.

- Canonical launch providers: connected `github` and unconnected `public-git`,
  including public GitHub/GitLab URLs. Connection presence and current caller
  grants select custody; a domain never does. Reserve connected `gitlab` without
  advertising it. Weft's resolver rename is a coordinated consumer cutover.
- Advertise bounded provider/mode pairs and optional validated
  `default_converter_version`. No marker means an explicit chooser; lexical
  converter ordering never selects a default.
- Add authenticated caller-bound `ResolveImportSource` for connected and public
  discovery, independent repository/ref object format, and a required explicit
  Prepare custody selector. Unknown format blocks Prepare/signing; known OIDs
  must agree with format and remain pinned. Prepare and Commit recheck current
  source grants, advertised support, algorithms and exact selected options.
- Rust/TS share generated resolver/configuration/discovery/Prepare vectors and
  signed SHA-256 observe controls. Separate remaining-parent operation/byte
  budget negatives and outer 2 MiB probes discriminate the gates they exercise.

Signed HYBRID layouts and domains are unchanged. Wire additions require the
semantic cutover above; alpha.23/24 epoch, cancellation, remaining-scope parent,
renewal, window, initial-lineage and exact-replay rules remain settled.
