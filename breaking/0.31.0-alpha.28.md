the newest published compatible heddle 0.28.7 / API alpha.19 pair.

  co-signed ownership claims/resolutions. BoundaryAcceptance retains the exact
  second creator binding plus current signed acceptance/manifest/intent/receipts.

  canonical vectors remain byte-identical after generator regeneration. See
  [the exact normative layouts](../docs/alpha-v2/native-host-witness.md).

  cutover; present evidence always needs explicit negotiated HYBRID support.
  Disposable staging histories reset; no conversion/re-witnessing or legacy trust.
  Downstream native producer/install implementations must consume this contract.
