# alpha.32 consumer additions: PR #352 verification evidence

Baseline: `36b06262d45209a8ab4400164827de05e8a83043`.
API only; all package versions remain `0.31.0-alpha.32`.

The new response field is `GetImportJobStateResponse.control_availability = 6`
(TS `controlAvailability`), with required `retry`, `renew`, `cancel` values.
`ImportControlAvailabilityV1.availability` is either `available=true` or
`unavailable=ImportControlUnavailableReason`. Reasons 1–8 are
`NOT_CONNECTION_OWNER`, `GRANT_MISSING`, `TERMINAL`, `ORIGINAL_WINDOW_ENDED`,
`NO_RETRY_TARGET`, `COMMIT_UNAVAILABLE`, `AUTHORITY_EXPIRED`,
`AUTHORITY_NOT_YET_VALID`. These are caller-relative read-time advice. Admission
still enforces the current exact connection, grant, commit, authority and CAS.

The composition signatures now take owner facts with no historical clock:

```rust
verify_import_bundle_witnesses(
    bundle: &ImportPublicProofBundleV1,
    pin: &ImportWitnessRootPin,
    snapshot: Option<&ImportWitnessSnapshot>,
    now_ms: i64,
    owners: &[ImportBundleOwnerExpectation<'_>],
    verify_policy: impl FnMut(&ImportPublicProofBundleV1,
        Option<&HostedWitnessStatementV1>) -> Result<(), Reject>,
) -> Result<VerifiedImportBundleWitnesses, Reject>
```

```ts
verifyImportBundleWitnesses(
  bundle: ImportPublicProofBundleV1,
  pin: ImportWitnessRootPin,
  snapshot: ImportWitnessSnapshot | undefined,
  now: bigint,
  owners: readonly ImportBundleOwnerExpectation[],
  verifyPolicy: (bundle: ImportPublicProofBundleV1,
    statement: HostedWitnessStatementV1 | undefined) => void | Promise<void>,
): Promise<VerifiedImportBundleWitnesses>
```

`ImportBundleOwnerExpectation` omits `now_unix_seconds` / `nowUnixSeconds`.
The returned `owner_check_times_unix_seconds` / `ownerCheckTimesUnixSeconds` come
from authenticated first publications, else initial admission, with absent times
for unwitnessed delegations. Each individual admission/publication is also checked
at its own authenticated observation. Consumers need no selection implementation.

The result retains typed `evidence` and the CAS read state, and adds
`snapshot_advanced` / `snapshotAdvanced`. `snapshot` is now optional.
Recovery without a new authenticated set returns the input snapshot unchanged,
including absence. A new authenticated set may advance root/set trust and clock;
recovery preserves admitted history and job-key associations, so an unwitnessed
activation tail never becomes authenticated persisted history. Scheduled Commit
asserts Recovery, absent owner time, new-set-only advancement, and empty admitted
history. Every existing admission/execution-window check remains in force.

`ImportControlAvailabilityContext` carries the host's read, logical terminal state,
original-admission fact and read clock. No account or connection detail is present
in the availability message. Cancel is independent of source custody/access.
