# Alpha.33 verification evidence

Baseline alpha.32 is `77f73219`. Git-root PR #354 is merged in `ab1aec46`.
Commands use an isolated Cargo target directory; no shared-target clean, stash
or force push was used.

## Fail-then-pass

These checks mutate each implementation guard temporarily, require a real failing
test, restore the exact source/built bytes in `finally`, and require a passing
control. Rust failures must be libtest failures, not compilation failures.

```sh
node tools/verify-alpha33-guards.mjs
CARGO_TARGET_DIR=/runner/heddleco-build/scratch/api-alpha33-target python3 tools/verify-alpha33-guards.py
```

| Property | Mutation | TS broken/restored exit | Rust broken/restored exit |
| --- | --- | --- | --- |
| P1 outside `[N,E)` refuses Expired | remove P1 delegation window/owner verification | 1 / 0 | 101 / 0 |
| P1/P3 transaction time/order | remove equal millis/transaction and P1-before-P3 guard | 1 / 0 | 101 / 0 |
| 24 h accepted | inject a 3600-second delegation cap | 1 / 0 | 101 / 0 |
| Duplicate sibling ref at Commit | remove conflicting-ref/target/genesis predicate | 1 / 0 | 101 / 0 |
| Cumulative 2× publication budget | disable live and historical cumulative byte checks | 1 / 0 | 101 / 0 |

P1 tests also cover exclusive expiry, foreign transaction and P1 without any
publication. The budget negatives use two operations individually below the
certificate limit whose sum is one byte over it; the control authorizes the
exact sum under ONE delegation. Commit exclusivity uses valid signed duplicate
proposals prepared without an exclusive ref inventory, then refuses the second
Commit against the first active job; the disjoint sibling succeeds.

Detailed logs are written by the tools to `/tmp/api-alpha33-guards/` and
`/tmp/api-alpha33-rust-guards/` as `<property>-red.log` and `-green.log`.
The vector-continuity gate was separately exercised with a deliberately incorrect
manifest hash (exit 1), then the exact manifest was restored (exit 0). No fixture
signature was edited for that demonstration.

fixture. The [exact alpha.32 comparison](0.31.0-alpha.33-vectors.json) verifies:

an addition plus retirement rather than a changed positional record.

Non-import native canonical records/signatures remain byte-identical. Native
boundary/set/seal carriers that depend on the rebuilt import witness archive
are listed individually as changed. Owner rotation and deferred-owner effective
expiry vectors remain generated through the maintained generator, independently
of the removed renewal flow.
