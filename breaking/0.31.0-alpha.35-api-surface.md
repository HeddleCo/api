# alpha.35 API surface

API-only fix round for PR #358. Version remains `0.31.0-alpha.35`. No protobuf
layout, signing domain, npm export path or native dependency pin changes.

The Rust `writer_authority` module and `@heddleco/api/v2/writer-authority` export
provide these portable checks. `decode_authority`, `verify_account_binding`, and
`check_writer_keys` keep their existing signatures (TS: `decodeWriterAuthority`,
`verifyWriterAccountBinding`, `checkWriterKeys`).

```rust
pub fn verify_landing_actor_binding(
    payload: &HostedLandingWitnessV1,
    verified_token_subject: &[u8],
    verified_token_subject_key: &[u8],
    verified_request_proof_key: &[u8],
    spool_account: &[u8],
    spool_owner_id: &[u8],
) -> Result<(), Reject>;
pub fn verify_authority_actor_binding(
    payload: &ImportAuthorityWitnessV1,
    verified_author_or_claim_account: &[u8],
    spool_account: &[u8],
    spool_owner_id: &[u8],
) -> Result<(), Reject>;
pub fn retained_mint_root_issuer(
    verified_history: &OwnerHistory, state_hash: &[u8], sequence: u64,
) -> Result<RetainedMintRootIssuer, Reject>;
pub fn admitted_owner_mint_root_attachment(
    authenticated_statement: &HostedWitnessStatementV1,
    payload: WriterWitnessPayload<'_>,
) -> Result<AdmittedMintRootAttachment, Reject>;
pub fn verify_retained_writer_attachment(
    attachment_bytes: &[u8], mint_root_public_key: &[u8],
    issuer: &RetainedMintRootIssuer, admitted: &AdmittedMintRootAttachment,
    now_unix_seconds: i64,
) -> Result<(), Reject>;
```

`WriterWitnessPayload` has `NativeGenesis(&NativeGenesisWitnessV1)` and
`Import(import_authority::WitnessPayload)` variants. The latter supports import
P1, P2 and P4. Both returned fact types have private fields. The old raw
`RetainedMintRootExpectation` input is removed; the raw
`verify_retained_owner_mint_root_attachment` is crate-private.

```ts
verifyLandingActorBinding(p: HostedLandingWitnessV1,
  verifiedTokenSubject: Uint8Array, verifiedTokenSubjectKey: Uint8Array,
  verifiedRequestProofKey: Uint8Array, spoolAccount: Uint8Array,
  spoolOwnerId: Uint8Array): void;
verifyAuthorityActorBinding(p: ImportAuthorityWitnessV1,
  verifiedAuthorOrClaimAccount: Uint8Array, spoolAccount: Uint8Array,
  spoolOwnerId: Uint8Array): void;
retainedMintRootIssuer(verifiedHistory: OwnerHistory,
  stateHash: Uint8Array, sequence: bigint): RetainedMintRootIssuer;
admittedOwnerMintRootAttachment(authenticatedStatement: HostedWitnessStatementV1,
  payload: WitnessPayload | {kind: "native-genesis"; payload: NativeGenesisWitnessV1}
): Promise<AdmittedMintRootAttachment>;
verifyRetainedWriterAttachment(attachmentBytes: Uint8Array,
  mintRootPublicKey: Uint8Array, issuer: RetainedMintRootIssuer,
  admitted: AdmittedMintRootAttachment, nowUnixSeconds: bigint): Promise<void>;
```

TS fact types use private WeakMap storage and reject caller-created lookalikes.
The raw TS retained verifier is private. Admission snapshots the statement and
payload before asynchronous verification. Both languages strict-decode the raw
certificate bytes before accepting a retained attachment.

`import_authority::policy_state_digest(&SignedPolicyBody)` / TS
`policyStateDigest(body)` expose canonical fields 1–10 hashing. The existing
`require_policy_history` now enforces those hashes, present policy bodies,
strict ascending `(spool_uuid, sequence)` carrier order, and grow-only revocations
on every selected predecessor. Hash/body checks cover every carried record before the zero-head shortcut. Owner signature and history verification remain
mandatory native checks. Bundle validation rejects duplicate owner-history
`state_hash` entries before resolving context, selects the Spool account from
signed identity/transfer records, applies cuts to both P2 ownership signers,
and accepts only native ThreadControl Review operations in P4 review evidence.

Receiver (heddle) MUST use both actor binding helpers after independent native
verification, and MUST use both fact derivation helpers before the retained
certificate verifier. Read the mandatory ordering and verified-input
preconditions in [the witness contract](../docs/alpha-v2/import-authority-host-witness.md).
API transport checks alone do not verify owner histories, sealed Biscuit tokens,
causal closure, role fencing, inherited policy, witness trust or host transactions.

The TS portable context helpers used across runtime modules are also exported:

```ts
validateOwnerHistories(histories: readonly OwnerHistory[]): void;
spoolAccountForStatement(s: HostedWitnessStatementV1,
  identities: readonly ImportIdentityV1[],
  transfers: readonly ResourceTransferAuditRecord[]): Uint8Array;
checkWitnessWriter(s: HostedWitnessStatementV1, envelope: Uint8Array,
  histories: OwnerHistory[], policies: SignedSpoolPolicyRecord[],
  spoolAccount: Uint8Array, coSigners?: readonly RecordSignature[]): void;
```

These enforce carrier uniqueness, signed-context selection and key cuts; their
inputs still require independent native authentication. Rust keeps these
cross-module functions crate-private.
