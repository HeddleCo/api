# 0.31.0-alpha.4 planned hard cut: public invitation inviter

This is the intentional pre-1.0 breaking override for
[api#249](https://github.com/HeddleCo/api/issues/249), slice 1. This branch
does not change package versions or publish a release. Consumers must update
together before alpha.4 is released.

`buf breaking --against '.git#ref=origin/main'` reports one intended FILE-level
break:

- `PublicOwner` moved `views.proto` → `common.proto`; wire/JSON/package-qualified
  name unchanged; TS import path changes. Rust/prost paths are unchanged.

`InvitationResolution` adds inviter and via-agent fields, gated by the held
redemption secret. The inviter is the accountable human, with only a public
handle and display name; a display name or agent label cannot stand alone.
The server and client behavior is implemented in later slices. The release
owner coordinates exact consumer pins and the alpha.4 tag.
