## Required changes

Heddle must remove the shell-safe alphabet from imported branch admission;
quote command arguments and encode storage paths instead. Its current rule
already allows `=`, `+`, `@`, but still rejects commas and non-ASCII names.
Both repos must preserve exact UTF-8 in their native mapping and import reports:
U+FFFD is a legitimate Git-valid UTF-8 name, not evidence that a decoder was
lossy, and Rust `trim()` can remove Git-valid non-ASCII whitespace from identity.
The reserved native `heddle/` namespace also needs a distinct/escaped storage
mapping for an imported Git branch of that name, rather than an additional
Git alphabet or namespace restriction. Keep original signed full refs intact.

Use the existing Sley 0.11.0 dependency, directly at native Git boundaries:
`BranchRefNameBuf::from_branch_name(short)` plus an explicit exact-`HEAD` check
for branches; `check_refname_format(full, false)` for general full refs.
`from_full` alone does not reject a leading `-` in the short branch name.
Never call `check_refname_format(short, true)` as the branch oracle: it rejects
short `@`, which is a valid branch. Preserve the API's independent 1024-byte
full-ref resource limit, known-OID pinning, signatures and authority checks.
A Sley syntax check cannot replace those checks. For validators below, the
Sley recommendation is explicit; embedding-only sites do not need a second
validator after a typed validated boundary.

Run the API shared corpus at each independent admission boundary. Exercise an
actual all-branches import containing `feat/mcp=timeout`, `a+b`, `user@x`,
`a,b`, `ünicode`, a literal U+FFFD, a branch ending with U+0085 and a quoted
shell-metacharacter name; replay/export/import its manifest in Rust and browser
code. Check exact UTF-8 byte/signature round trips, UTF-8 ordering versus
UTF-16, portable escaped storage, name collisions and command argv quoting.
These are follow-up consumer checks; this API PR does not claim to have run a
live Heddle/Weft import or changed their deployed packages.
