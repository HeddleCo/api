# 0.31.0-alpha.44: approval-group explicit handle validation

Rust and TypeScript approval-group validators now classify each explicit member
handle using the same canonical namespace rules as people metadata, rather than
validating every handle as Native. `gitlab.com:Alice` and `github.com:bob` are
accepted unchanged. `gh:name` remains GitHub kind; canonical lowercase DNS
provider hosts containing a dot use GitLab kind, including `github.com`.

Malformed provider hosts, empty handles, UUID-shaped handles, leading/trailing
whitespace and control characters remain invalid metadata. No protobuf or
membership-resolution semantics change. Hosts still resolve visible human
handles to private stable subject bindings after administrator authorization.

Cargo and npm packages move together to `0.31.0-alpha.44`.
