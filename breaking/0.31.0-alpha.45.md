# 0.31.0-alpha.45: import discovery accepts up to 4096 refs

HYBRID import Prepare and Commit accept a complete current source discovery of
up to `MAX_IMPORT_SOURCE_REFS` (4096) branch/tag refs (HeddleCo/api#388, #389),
up from 512. New exported constants: `MAX_IMPORT_SOURCE_REFS` (4096) and
`MAX_IMPORT_SOURCE_REF_PAGE` (512), plus `validate_discovered_repository` /
`validateDiscoveredRepository` for complete discovery. One ResolveImportSource
page stays capped at 512 refs. Every discovered ref name must be at most 1024
UTF-8 bytes (`MAX_REF_BYTES`), or the source refuses with `Bounds`. No tags,
wire bytes, signed records or fixture vectors change.

Cargo and npm packages move together to `0.31.0-alpha.45`.
