# 0.31.0-alpha.46: incremental import discovery and opt-in pull-request heads

HeddleCo/api#400 raises the complete-discovery work ceiling from 4,096 to
1,048,576 refs. A safety ceiling bounds hostile advertisement CPU work without
requiring retention of the complete advertisement. Pages remain capped at 512
refs and names at 1,024 UTF-8 bytes; signed selections remain capped at 256.

Rust and TypeScript export `DiscoveryValidator`, `DiscoveryDigest`,
`DiscoveryOptions`, `DiscoverySelectionMode`, the complete-list digest adapter,
and Prepare/Commit helpers accepting finished local evidence. The validator
retains a running SHA-256, one previous name, bounded source metadata and at most
256 selected records/membership flags. Strict global UTF-8 ordering proves
uniqueness. Hosts must authenticate snapshot/cursor continuity and complete
coverage before finish; digest evidence is not a signed record or authorization.

Namespace/kind checks and selected-ref membership fail closed. Existing
metadata-only conformance carriers remain byte-for-byte unchanged; admission
tests supplement them with independent complete host discovery. Commit still
preserves frozen pins after head movement.

Additive `include_pull_request_refs` (tag 4) on `ProviderRefsRequest` and
`ResolveImportSourceRequest` opts in to `refs/pull/<positive decimal>/head`.
Additive `ProviderRef.Kind.KIND_PULL_REQUEST` (3) labels them. Zero, leading
zeros and merge refs are excluded. Cursors bind the option. False/omitted keeps
branch/tag discovery. Existing tags, enum values, signed encodings, fixture
vectors and existing wire bytes do not change. No Buf breaking override is used.

Shared SHA-1/SHA-256 recipes cover 20,000 refs (8,000 branches, 8,000 pull-request
heads, 4,000 tags), page partitions of 1/127/512 and identical digest expectations
in both languages. Tests also cover page-local failures, cross-page duplicate
names, failed-validator reuse, absent selections, pin movement, opt-in namespace
rules, exact ceiling/overflow and every existing repository fixture against the
former one-pass checks.

Cargo and npm packages move together to `0.31.0-alpha.46`. Tagging and publication
remain separate release steps.
