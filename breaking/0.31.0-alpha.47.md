# 0.31.0-alpha.47 — additive collaboration and file outlines

Closes HeddleCo/api#407 and HeddleCo/api#406 in one API release candidate.
Cargo and npm advance together from alpha.46 to alpha.47.

- Add principal and pinned source mentions to signed collaboration, opening
  discussion turns and context drafts/records. Reuse `EntityRef.principal` and
  add `EntityRef.source` / `SourceMention`, aligned with `SourceAnchor`.
- Add discussion `AnnotationTag` lists, versioned `EditDiscussionTags` and a
  discussion-only `AnnotationQuery` filter in collaboration observations.
- Add paged `ReadContent` outline selections and per-symbol events, using the
  existing revision-bound completion coverage, page information and safe reason.
- Add matching Rust/TypeScript bounds validators and seven shared signed golden
  vectors, plus native conformance for existing and new mention components.

All changes are additive. Buf lint and breaking against main require no override.
Existing fields/oneofs/enum values and canonical signed bytes are unchanged.
Empty opening tags omit the new signed key. Older consumers refuse unfamiliar
signed variants; upgraded hosts must implement their schema/causal admission
and the documented notification/source disclosure gates before accepting them.

See [mentions/tags](../docs/alpha-v2/collaboration-mentions-tags.md) and
[outline](../docs/alpha-v2/content-outline.md) for the normative contracts.
