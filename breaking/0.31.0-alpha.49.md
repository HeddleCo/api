# 0.31.0-alpha.49: bounded import jobs and linear Commit proofs (api#413)

Cargo and npm advance together. New import jobs use proof carrier format 2:
`creator_authority_envelopes` is a digest-sorted unique table, addressed through
the existing signed manifest → genesis-authority → envelope digest chain.
Signed records, domains, original bytes and existing frozen fixtures are unchanged.

An additive `GetImportConfigurationResponse.import_proof_bundle_format_version`
(tag 5) explicitly advertises support. Zero/1 retains the frozen format-1 contract;
2 enables the new contract; unknown values reject. No automatic format fallback.
New hosts advertise at most 25 branches. The 64 KiB record cap stays unchanged;
format 2 uses a 4 MiB proof / 8 MiB request cap and a 64 KiB initial-Commit context
reserve. Format 1 keeps its 1 MiB / 2 MiB caps and existing verification, including
old 256-count scope vectors. Native carriers and discovery/configuration responses
keep their 1 MiB caps. Operations/history retain their existing 256 ceiling.

The shared Rust/TS greedy partition helper measures complete candidate jobs with
the canonical signed-record and protobuf proof encoders. Shared golden inputs,
output digests and exact boundary sizes exercise count, record bytes, proof bytes,
mixed limits and one-byte-smaller budgets; every output verifies.

[The contract](../docs/alpha-v2/import-partition.md) gives complete arithmetic:
`2,904 + 2,420N` is 63,404 bytes at 25 and 65,824 at 26; conservative complete
Commit proof material is at most 3,603,581 bytes at 25, below 4 MiB. Actual
worst-ref Commit verification uses a 63,350-byte delegation and 150,928-byte proof.
The 16/64/256 probes measure 84,444/909,182/12,871,710 bytes before and
29,184/108,578/426,435 bytes after. The larger probes measure encoding only.

Consumers must use explicitly advertised format 2, update the job maximum and
request/proof transport bounds, call the partition helper with complete material,
and finish signing/verification before submission. Delivery order is api → heddle
→ weft → clients; this PR changes the public API contract, not downstream hosts.
Buf changes are additive; **no breaking override is required**.
