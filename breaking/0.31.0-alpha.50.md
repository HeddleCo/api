# 0.31.0-alpha.50 — additive immutable SOURCE objects

Adds opt-in OpenObjectSnapshot/ReadObjects protobuf RPCs, generated Rust and
TypeScript types, matching bounded validators/decoders, canonical authority and
per-range cache keys, and shared golden vectors. Existing Fetch, wire tags,
signed native/import formats and advertised mandatory features are unchanged.
Buf breaking against main requires no override.

Snapshots carry a complete bounded inventory for an exact native State/Thread,
authority/view epochs, per-user AND signing-principal scope, explicit limits,
and a host-advertised maximum cache TTL after revocation (default 60 seconds).
No synchronous edge revocation gate is required. Cache hits cannot refresh the
live-check deadline. See [the contract](../docs/alpha-v2/immutable-objects.md).

Cargo and npm advance together from current main's untagged alpha.49 to
alpha.50. Native and custodial conformance lockfiles follow the local package
version. This note does not publish or tag a release.
