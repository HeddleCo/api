# 0.31.0-alpha.7 planned hard cut: timeline origin Biscuit signature-v1

This is the intentional pre-1.0 breaking override for
[api#260](https://github.com/HeddleCo/api/issues/260) and the owner decision in
[heddle#1840](https://github.com/HeddleCo/heddle/issues/1840). This branch does
not change package versions or publish a release. Consumers and producers must
update together before alpha.7 is released.

Every block in an offline timeline origin Biscuit chain, including the authority
block, MUST use signature-v1. A chain containing any signature-v0 block is
rejected. Signature-v0 chains accepted by alpha.6 are no longer eligible for
registration or upload. There is no legacy acceptance path.

The `heddle-timeline-run-origin-v3` transcript and `derivation_path_sha256`
remain byte-for-byte unchanged. There is no protobuf wire or generated-code
change; `buf breaking` reports no diagnostics.
