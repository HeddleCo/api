# 0.31.0-alpha.9 planned hard cut: per-branch Git import geneses

This is the intentional pre-1.0 breaking override for
[api#267](https://github.com/HeddleCo/api/issues/267), part of
[weft#2369](https://github.com/HeddleCo/weft/issues/2369). Pilot import data is
disposable, so producers and consumers move together to the new request shape.

`ImportSourceRequest` removes the single `thread_genesis` field 5 and its
separate `creator_authority` field 6. Both field numbers and names are reserved.
Callers now send `branches` field 8 with a ref name, creator-signed `SignedRecord`
Thread genesis, and creator authority for each branch. There is no dual-read or
legacy fallback. The existing optional `initial_base_state` field 7 remains and
must match the base committed by each supplied branch genesis when used.

`OperationRecord.import_report` field 14 adds import fidelity, counts of
commits/branches/tags, and named skipped refs with reasons. This alpha does not
add discovery, staging, or proof-transport messages.

`buf breaking --against '.git#branch=origin/main,subdir=proto'` reports the
intentional removal of the two old request fields. This report is the
pre-1.0 override required by `COMPATIBILITY.md`.
